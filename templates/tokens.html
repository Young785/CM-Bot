How to Extract
  1. Open Firefox with logged-in Codementor
  2. Press F12 for Developer Tools
  3. Go to Console tab
  4. Type: document.cookie.match(/ACCESS_TOKEN=([^;]+)/)[1]
  5. Copy the token (starts with "eyJ...")
  6. Paste and Save
